# Customer Churn Prediction | Predicción de Abandono de Clientes

## English

### What it does
This project predicts which customers are likely to leave a service and identifies the factors associated with churn. It supports retention actions before valuable customers leave.

### How it works
The project prepares customer data, explores risk patterns, trains classification models, and evaluates them with precision, recall, F1-score, and ROC-AUC. Model results are translated into a practical retention strategy.

### Why it matters for future applications
It can evolve into a production scoring API, a CRM alert system, an automated retraining pipeline, or an experimentation platform that measures whether retention campaigns work.

## Español

### Qué hace
Este proyecto predice qué clientes tienen probabilidad de abandonar un servicio e identifica los factores asociados al abandono. Permite actuar para retener clientes valiosos antes de perderlos.

### Cómo funciona
Prepara los datos de clientes, explora patrones de riesgo, entrena modelos de clasificación y los evalúa con precision, recall, F1-score y ROC-AUC. Los resultados se traducen en una estrategia práctica de retención.

### Para qué sirve en aplicaciones futuras
Puede evolucionar a una API de scoring en producción, un sistema de alertas en CRM, un pipeline de reentrenamiento automático o una plataforma de experimentación para medir campañas de retención.

## Stack

Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Jupyter.
